# Task 4 telemetry handoff

Read README_telemetry.md for the assembler instructions. Three saved Monza lap exports are included. Run `python demo_telemetry.py` to inspect them offline without an F1 account or third-party packages.

For fresh FastF1 downloads only, install requirements.txt and use your own Formula 1 sign-in if required: `python -m fastf1 auth f1tv --authenticate`. Reading the saved CSVs needs no sign-in.
